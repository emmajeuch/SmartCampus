# Conception

- `mcd.mcd` : le MCD écrit pour [Mocodo](https://www.mocodo.net) (outil libre et gratuit). Pour le modifier : copier le texte sur mocodo.net, corriger, puis exporter l'image.
- `mcd.png` et `mcd.svg` : le dessin du MCD.

Les raisons de chaque cardinalité sont dans l'onglet « MCD (guide) » du Google Doc du groupe.
